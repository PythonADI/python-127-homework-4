# Submissions

One folder per student, named after your GitHub username:

```
submissions/
  nino-b/
    exercise_1.py
    exercise_2.py
    ...
  giorgi-k/
    exercise_1.py
    exercise_2.py
    ...
```

Only touch your own folder. See [../SUBMITTING.md](../SUBMITTING.md)
for the full walkthrough.
